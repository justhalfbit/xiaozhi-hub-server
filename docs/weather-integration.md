# 天气插件使用指南

## 概述

天气插件 `get_weather` 可以用语音查询各地的天气：现在的天气、未来 7 天预报、接下来 12 小时会不会下雨下雪、空气质量（PM2.5）。

- 天气和空气质量来自 [Open-Meteo](https://open-meteo.com/)，地名用 [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) 换成经纬度（查不到再试 Open-Meteo 自带的地名查询）。
- 都是免费服务，不用注册，也不用填 Key。
- 城市、区县、国外城市都能查，例如「杭州」「深圳南山区」「东京」；景点按它所在的区县或城市查。

> 以前的版本用和风天气。项目共用的和风 Key 已经失效，天气数据还是抓网页解析的，现已舍弃，不再需要 `api_key`、`api_host`。

## 所在地

没说地点时（例如「今天天气怎么样」「明天要带伞吗」）查所在地的天气，按下面的顺序决定所在地：

1. 后台「意图识别」页，查天气旁边的「设置」里填的所在地（可以写到区县）；
2. 没填就按宽带的公网 IP 判断城市（只到城市级，运营商出口在外地时会不准）；
3. IP 也判断不出来时，用配置里的 `default_location`（默认广州）。

设置页的「测试」按钮会用填的所在地查一次，显示实际查到的地点，方便确认地名认得对不对。

## 配置文件

也可以直接改 `data/.config.yaml`：

```yaml
plugins:
  get_weather:
    location: "深圳南山区"   # 留空按 IP 判断
    default_location: "广州"
```

## 说明

- Nominatim 要求每秒最多查 1 次、结果要缓存。插件会把查过的地名一直缓存在内存里，同一个地方只查一次；天气缓存 1 小时。
